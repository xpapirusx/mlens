# Changelog

Только заметные пользователю изменения — коротко и по-человечески. Новые версии
сверху. Формат: `## vX.Y.Z — DD.MM.YYYY, HH:MM`.

---

## v2.4.43 — 19.11.2026, 13:59

- **Новая вкладка кластера с клавиатуры**: `⌘N` / `Ctrl+N` открывает каталог,
  чтобы выбрать кластер (кнопка «+» делает то же самое).
- **Навигация по вкладкам**: `⌘⇧]` / `⌘⇧[` переключают вкладки кластеров,
  `Ctrl+Tab` / `Ctrl+Shift+Tab` — вкладки ресурсов в активной панели.
- **Подсказки хоткеев**: в тултипах кнопок «+» (новая вкладка), настроек,
  нового терминала и закрытия вкладки теперь видно сочетание клавиш.
- **Меню хоткеев** стало доступнее: кнопка с клавиатурой в верхней панели,
  пункт «Keyboard shortcuts» в командной палитре, плюс прежний `?`.

## v2.4.42 — 19.11.2026, 13:54

- **⌘W / Ctrl+W** больше не закрывает всё приложение: сначала закрывается
  активная вкладка редактора, затем — активная вкладка кластера. В терминале
  сочетание по-прежнему отдаётся шеллу.
- **⌘F / Ctrl+F** теперь фокусирует поиск: на странице каталога — поиск
  кластеров, в кластере — поиск по таблице. В YAML-редакторе и терминале
  остаётся их собственный поиск.
- **Цвета кластеров**: в контекстном меню хотбара можно выбрать цвет плитки —
  он запоминается для кластера. В настройках появился раздел **Cluster colors**
  с regex-правилами (`*prod*` — красный, `*test*` — жёлтый и т.п.); первое
  совпадение выигрывает, при отсутствии — прежний автоматический цвет. Каталог
  использует те же цвета.

## v2.4.41 — 19.11.2026, 13:24

- **Импорт kubeconfig** принимает любой файл (не только `.kubeconfig`):
  содержимое проверяется, файлы без контекстов отклоняются с ошибкой, остальные
  выбранные файлы всё равно добавляются.
- Кнопка **Port forwards** вернулась в верхнюю панель — список активных
  пробросов снова можно открыть.
- Шрифты: добавлены **JetBrains Mono**, **Fira Code**, **Source Code Pro** и
  **Tinos (Times-like)**; любой встроенный шрифт теперь можно выбрать как
  **UI font**. Лицензии разложены по файлам, проприетарные Times New Roman,
  Menlo, Monaco и SF Mono не поставляются.
- README переработан, добавлен скриншот каталога; история changelog дополнена
  с версии **0.1.0**.
