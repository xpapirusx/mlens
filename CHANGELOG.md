# Changelog

Только заметные пользователю изменения — коротко и по-человечески. Новые версии
сверху. Формат: `## vX.Y.Z — DD.MM.YYYY, HH:MM`.

---

## v2.4.63 — 19.11.2026, 21:09

- Exec в под теперь понимает **командную строку**, как kubectl/Freelens:
  `sh -c "clear; (bash || ash || sh)"` (и любой другой набор аргументов)
  выполняется корректно, а не как один «бинарник» с пробелами в имени.
- В диалоге Exec по умолчанию подставляется цепочка bash → ash → sh
  (кандидаты проверяются через `command -v`, лишних ошибок нет), поэтому
  терминал открывается чистым.
- Исправлен код выхода: `exit 7` показывает 7, а не 0. Если оболочки в
  контейнере нет, вместо голой OCI-ошибки выводится подсказка.

## v2.4.62 — 19.11.2026, 20:17

- Поиск в таблице ресурсов теперь ищет **только по имени**: запрос
  `salt-operator` больше не показывает поды `salt-servant`, которые просто
  лежат в одноимённом namespace.
- Namespace, статус, лейблы и остальные колонки по-прежнему фильтруются
  колоночными фильтрами; regex-режим тоже проверяет только имя.

## v2.4.61 — 19.11.2026, 20:08

- Кастомные ресурсы, чьё имя вида совпадает со встроенным (`Node` в группе
  `metalmonk.pinata.mws.cloud`), больше не получают чужие колонки: показываются
  printer-колонки CRD, а Status берётся из generic-статуса вместо `Unknown`.
- Такие ресурсы открываются с обычным Overview и без действий Node — не
  предлагаются Drain, Cordon, Metrics, Logs и подмена Conditions/Taints.

## v2.4.60 — 19.11.2026, 19:56
